Привет! Мы создаем Telegram-юзербота на Python в Docker. Нам нужно реализовать только Фазу 1 (Фундамент и Эхо-логика). Никакого ИИ, никаких баз данных и сложных таймингов на этом этапе быть не должно. Пиши чистый, современный код без «галлюцинаций» и лишних наворотов.

Используй следующий современный стек:
- Язык: Python 3.12+
- Менеджер пакетов и сборщик: uv (от Astral)
- Библиотека Telegram: Telethon (последняя стабильная версия)

Требования к структуре проекта:
Создай 4 файла в одной папке:
1. pyproject.toml — конфигурация проекта для uv.
2. requirements.txt (или uv.lock) — управление зависимостями.
3. Dockerfile — мультиэтапная сборка (multi-stage) с использованием официального образа ghcr.io/astral-sh/uv для максимальной легковесности.
4. docker-compose.yml — для удобного запуска и монтирования сессии.
5. main.py — основной асинхронный код юзербота.

Логика main.py (Строго Эхо):
1. Бот инициализируется через TelegramClient, используя API_ID и API_HASH из переменных окружения (os.getenv).
2. Бот должен слушать только входящие новые сообщения (events.NewMessage(incoming=True)).
3. Жесткий фильтр: бот реагирует ТОЛЬКО на приватные сообщения (личные чаты). Он должен полностью игнорировать групповые чаты, каналы и сообщения, отправленные самим владельцем аккаунта.
4. Ответная реакция: бот берет текст входящего сообщения и отправляет его обратно собеседнику в неизменном виде (Эхо).

Требования к авторизации в Docker:
- Файл сессии Telethon должен сохраняться в корень проекта под именем `userbot.session`.
- Чтобы мы могли пройти первичную авторизацию (ввести номер телефона и код из Telegram прямо в консоли), docker-compose должен поддерживать интерактивный режим (stdin_open: true, tty: true), а файл сессии должен пробрасываться через volume, чтобы не стираться при перезапуске контейнера.

Напиши структуру pyproject.toml, Dockerfile, docker-compose.yml и main.py. Код должен быть готов к запуску.
